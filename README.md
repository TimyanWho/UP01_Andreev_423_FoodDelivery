# Сервис доставки еды

WPF-приложение на .NET Framework 4.8, SQL Server и Entity Framework 6 через ADO.NET Entity Data Model (EDMX). Контекст и классы сущностей модели входят в проект.

## Структура

- `Core.cs` — общий контекст Entity Framework.
- `Helpers.cs` — хеширование паролей, проверка введённых данных и генерация капчи.
- `AppSession.cs` — текущая сессия пользователя и состояние капчи.
- `Pages/` — XAML-страницы и их обработчики событий. Панель администратора обращается к каждому набору `Core.Context` напрямую.
- `Model.edmx`, `Model.Context.cs` и классы сущностей — модель базы данных, созданная Visual Studio.
- `db/schema.sql` — скрипт создания базы `UP01_Andreev_423_FoodDelivery`, 12 таблиц, ключей, ограничений, индексов и тестовых данных.
- `res/` — каталог ресурсов приложения.

## База данных

`db/schema.sql` пересоздаёт таблицы и заменяет тестовые данные. Запускай его только для первоначального создания или полного сброса учебной БД. Не запускай его поверх базы с данными, которые нужно сохранить.

Имя контекста — `UP01_Andreev_423_FoodDeliveryEntities`. Если приложение не подключается к SQL Server, проверь имя сервера и строку подключения в `App.config`.

## Тестовые учётные записи

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin` | `admin123` |
| Пользователь | `timyan` | `user123` |
| Пользователь | `ivan` | `ivan123` |
| Пользователь | `anna` | `anna123` |
| Курьер | `courier` | `courier123` |

Это учебные демонстрационные данные. В базе пароли хранятся как PBKDF2-хеши, а не открытым текстом.

## Возможности

- авторизация, регистрация и смена пароля;
- проверка введённых данных, хеширование паролей и капча после трёх неверных попыток;
- пользовательский каталог, поиск, сортировка, корзина, оформление заказов, адреса и отзывы;
- кабинет курьера для принятия и завершения доставки;
- панель администратора с поиском, сортировкой, добавлением, редактированием и удалением записей;
- диаграммы и экспорт в Word, PDF и Excel; для COM-экспорта необходимы установленные Microsoft Word и Excel;
- светлая и тёмная темы.

## Git

В репозитории хранится скрипт базы данных, а не запущенный экземпляр SQL Server. Добавь `README.md`, `db/schema.sql`, исходный код и ресурсы в Git, затем создай коммит и отправь его в удалённый репозиторий.
